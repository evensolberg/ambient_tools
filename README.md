# ambient_download

Download data from the Ambient Weather API.

> Work in progress. Expect changes.

Tools included in this repository:

- [Ambient Download](ambient_download/README.md): The main application for downloading data from the Ambient Weather API. The application is intended to be run as a cron job to download data from the API periodically. Earlier data can also be downloaded using this application.

Additional tools may be added in the future to process the data.

Additional information on the Ambient Weather API can be found [here](https://ambientweather.docs.apiary.io/).
